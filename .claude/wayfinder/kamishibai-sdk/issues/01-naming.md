# 專案命名

Status: resolved
Type: grilling

## Question

這個 Agent 專用呈現 SDK 專案要叫什麼名字？需能承接既有命名血緣（baransu／Kami 主題），且適合日後公開發佈。

## Answer

定名 **kamishibai**（紙芝居）——日本街頭說書以圖卡逐張呈現故事的技藝，與「把內容做成可呈現畫面」的本業直接對應，並與 Kami 主題血緣相連。候選 hyousou（表装）、butai（舞台）、utsuwa（器）皆落選。

Repo 已建立：https://github.com/TLOGBen/kamishibai （2026-08-16，Initial commit）。
